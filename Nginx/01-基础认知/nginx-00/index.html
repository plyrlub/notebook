    00 - 环境准备与实验搭建¶

    版本基线：Nginx 1.30.4 | OpenResty 1.29.2.1 | 创建日期：2026-08-05

    学习目标¶

    搭建一个可随时修改、随时重载的 Nginx 实验环境，让你在学习过程中能够边看文档边动手验证。环境包含 Nginx + Python 后端 + Java 后端，覆盖静态资源、反向代理、负载均衡、HTTPS 等所有学习场景。

    一、为什么需要实验环境¶

    服务器小白特别提示：学 Nginx 最怕"只看不练"。Nginx 的配置改一行就可能行为完全不同，必须亲手操作才能建立肌肉记忆。

    本实验环境提供：

    • Nginx 容器（配置文件挂载到宿主机，改完 nginx -s reload 即可生效）
    • Python 后端（Flask，模拟 API 服务）
    • Java 后端（Spring Boot，模拟 API 服务）
    • 自动签发的 HTTPS 证书（用于学习 HTTPS 配置）

    二、前置条件¶

    2.1 安装 Docker¶

    # macOS（推荐 Docker Desktop）
brew install --cask docker

# Ubuntu
curl -fsSL https://get.docker.com | sh
sudo systemctl enable docker
sudo systemctl start docker

# 验证安装
docker --version          # 查看版本
docker compose version    # 查看 compose 版本

    服务器小白解释：Docker 是一种容器化技术，可以把 Nginx、Python、Java 各自打包成独立"容器"运行，互不干扰。Docker Compose 则用来一键启动多个容器。

    2.2 创建实验目录¶

    mkdir -p ~/nginx-lab/{nginx/conf.d,nginx/ssl,nginx/html,backend-python,backend-java/src}
cd ~/nginx-lab

    目录结构如下：

    nginx-lab/
├── docker-compose.yml          # 一键启动所有容器
├── nginx/
│   ├── nginx.conf              # Nginx 主配置
│   ├── conf.d/                 # 子配置目录（学习时在这里写配置）
│   │   └── default.conf
│   ├── ssl/                    # HTTPS 证书
│   └── html/                   # 静态资源
│       └── index.html
├── backend-python/
│   ├── app.py                  # Flask 后端
│   └── requirements.txt
└── backend-java/
    ├── Dockerfile
    └── src/                    # Java 源码

    三、Docker-Compose 配置¶

    3.1 docker-compose.yml¶

    version: "3.8"

services:
  # Nginx 服务
  nginx:
    image: nginx:1.30
    container_name: nginx-lab
    ports:
      - "80:80"      # HTTP
      - "443:443"     # HTTPS
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/nginx.conf:ro           # 主配置（只读挂载）
      - ./nginx/conf.d:/etc/nginx/conf.d                      # 子配置（可读写，学习时改这里）
      - ./nginx/html:/usr/share/nginx/html                    # 静态资源
      - ./nginx/ssl:/etc/nginx/ssl                            # SSL 证书
      - ./nginx/logs:/var/log/nginx                           # 日志目录
    depends_on:
      - backend-python
      - backend-java
    networks:
      - lab-net
    # 容器内执行 nginx -t && nginx，先测试配置再启动
    command: ["nginx", "-g", "daemon off;"]

  # Python 后端（Flask）
  backend-python:
    build: ./backend-python
    container_name: flask-backend
    expose:
      - "5000"      # 仅对同一网络开放，不映射到宿主机
    environment:
      - APP_NAME=flask-backend
      - PORT=5000
    networks:
      - lab-net

  # Java 后端（Spring Boot）
  backend-java:
    build: ./backend-java
    container_name: spring-backend
    expose:
      - "8080"
    environment:
      - SERVER_PORT=8080
    networks:
      - lab-net

networks:
  lab-net:
    driver: bridge

    逐行说明：
    - image: nginx:1.30：使用 Nginx 1.30 稳定版镜像
    - ports: "80:80"：宿主机 80 端口映射到容器 80 端口（左宿主机右容器）
    - volumes：把宿主机目录挂载到容器内，改宿主机文件即等于改容器内文件
    - depends_on：Nginx 依赖后端服务先启动
    - expose：只在 Docker 网络内暴露端口，外部不可直接访问（通过 Nginx 反代）
    - daemon off;：Docker 容器需要前台运行，否则容器会立即退出

    3.2 Nginx 主配置 nginx.conf¶

    # nginx/nginx.conf
user  nginx;                          # worker 进程运行用户
worker_processes  auto;               # 自动匹配 CPU 核心数

error_log  /var/log/nginx/error.log warn;
pid        /var/run/nginx.pid;

events {
    worker_connections  1024;          # 单 worker 最大连接数（学习环境足够）
}

http {
    include       /etc/nginx/mime.types;   # MIME 类型映射
    default_type  application/octet-stream;

    # 日志格式
    log_format  main  '$remote_addr - $remote_user [$time_local] "$request" '
                      '$status $body_bytes_sent "$http_referer" '
                      '"$http_user_agent" "$http_x_forwarded_for"';

    access_log  /var/log/nginx/access.log  main;

    sendfile        on;                 # 零拷贝发送文件
    keepalive_timeout  65;              # 客户端长连接超时

    # 加载 conf.d 目录下的所有 .conf 文件（学习时在这里写配置）
    include /etc/nginx/conf.d/*.conf;
}

    3.3 默认配置 conf.d/default.conf¶

    # nginx/conf.d/default.conf
server {
    listen       80;
    server_name  localhost;

    location / {
        root   /usr/share/nginx/html;
        index  index.html;
    }

    # 反向代理到 Python 后端
    location /api/python/ {
        proxy_pass http://backend-python:5000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 反向代理到 Java 后端
    location /api/java/ {
        proxy_pass http://backend-java:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

        "forwarded_for": request.headers.get("X-Forwarded-For", "unknown"),
    })

@app.route("/health")
def health():
    """健康检查端点"""
    return jsonify({"status": "ok"}), 200

if __name__ == "__main__":
    port = int(os.environ.get("PORT", 5000))
    app.run(host="0.0.0.0", port=port)

    六、生成自签名 HTTPS 证书¶

    学习 HTTPS 配置时需要证书。用 OpenSSL 生成自签名证书：

    # 进入 ssl 目录
cd ~/nginx-lab/nginx/ssl

# 生成自签名证书（学习用，浏览器会警告不安全，点"继续"即可）
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout server.key \
  -out server.crt \
  -subj "/C=CN/ST=Beijing/L=Beijing/O=NginxLab/CN=localhost"

# 设置适当权限
chmod 600 server.key

    逐行说明：
    - req：证书请求命令
    - -x509：直接生成自签名证书（而非 CSR）
    - -nodes：不对私钥加密（Nginx 需要无密码读取）
    - -days 365：有效期 365 天
    - -newkey rsa:2048：生成 2048 位 RSA 密钥对
    - -subj：证书主题信息（C=国家 ST=省 L=市 O=组织 CN=域名）

    学完阶段五的 HTTPS 配置后，把证书路径配到 Nginx 中：

    server {
    listen 443 ssl;
    server_name localhost;

    ssl_certificate     /etc/nginx/ssl/server.crt;
    ssl_certificate_key /etc/nginx/ssl/server.key;

    # ... 其他配置
}

    九、最佳实践¶

    1. 配置文件拆分：每个学习场景创建独立的 .conf 文件（如 proxy.conf、ssl.conf、cache.conf），在 default.conf 中用 include 加载，避免互相干扰
    2. 随时备份：改配置前先 cp default.conf default.conf.bak，出问题能快速回滚
    3. 善用 nginx -t：每次改完配置先测试语法，不要直接 reload
    4. 日志是朋友：遇到问题第一时间看 docker compose logs nginx 的 error 日志
    5. curl 调试：用 curl -v http://localhost/ 查看详细的请求/响应头，比浏览器更适合调试 Nginx
