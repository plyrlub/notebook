## 2.3 变量名命名

- 弱语言类型，定义变量名的时候不需要类型修饰
- 变量类型随时可修改，即赋值
- 每行代码后，有没有分号都可以
- 由数字、字母、下划线组成
- 不可以数字开头
- 不可以保留字
- 不可以特殊符号
- 不建议 下划线开头+字母大写
- 区分大小写
    ```lua
a = 124;
b = 123

a1 = 123
_a = 123
```

## 2.4 变量类型

- 全局变量
    ```lua
a = 1
```

- 局部变量
    ```lua
do
      local b = 1
    end
```

- 表字段

## 2.5 转义

和其他语言一样，

转义和原始输出案例：

```lua
local b = "a\rb\rc\td\te f\t [[aa]]";
print(b)

输出：
a
b
c       d               e f
c       d       e f      [[aa]]

local c = [=[a\rb\rc\td\te f\t [[aa]]]=];
print(c)

输出：
a\rb\rc\td\te f\t [[aa]]
```

即，需要原始输出需要使用

```lua
[=[

]=]
```
