## 1. self 与冒号语法

Lua 没有 class 关键字，用 table + function 模拟对象。**冒号 `:` 语法是语法糖**：`obj:method(args)` 等价于 `obj.method(obj, args)`——自动把调用者作为第一个参数 `self` 传入。

```lua
local t1 = {id=1, name='zs'}

local t2 = t1

t1.getId = function()
    return t1.id
end

print(t1.getId())
print(t2.getId())

-- 使用self，使用冒号的方法，默认自动传入第一个参数为self，即调用者对象
function t1:getId2()
    return self.id
end

t1 = nil
-- 这里获取不到，因为t1已经为nil了，无法获取到id
-- print(t2.getId())

-- 使用self之后，就可以获取到id了
print(t2:getId2())
```

**为什么用 self**：`t1.getId` 里直接引用了 `t1` 变量，一旦外部把 `t1` 置 nil 或重新赋值，方法就失效。而 `self` 是运行时传入的**调用者本身**，与外部变量名解耦——`t2:getId2()` 的 self 就是 t2，即使 t1 没了也能工作。

## 2. 构造函数（new）

```lua
-- 经典构造函数模式：模块返回一个表，含 new 方法
local Account = {}          -- 类（一个普通 table）
Account.__index = Account    -- 实例查找方法的关键：实例找不到的字段去类里找

function Account.new(balance)
    local self = setmetatable({}, Account)  -- 空表 + 元表 = 实例
    self.balance = balance or 0
    return self
end

function Account:getBalance()
    return self.balance
end

local acc = Account.new(100)
print(acc:getBalance())  -- 100
```

> 三要素：**类**（普通 table）→ **元表 `__index` 指向类**（实例能访问类方法）→ **`setmetatable({}, 类)` 创建实例**。

## 3. 继承

继承 = **子类的元表 `__index` 指向父类**（或指向父类实例）。实例查找字段时：自己 → 子类 → 父类，形成链条。

```lua
local Account = {}
Account.__index = Account

function Account.new(balance)
    local self = setmetatable({}, Account)
    self.balance = balance or 0
    return self
end

function Account:getBalance()
    return self.balance
end

-- 子类：继承 Account
local SavingAccount = setmetatable({}, { __index = Account })
SavingAccount.__index = SavingAccount

function SavingAccount.new(balance, rate)
    local self = Account.new(balance)      -- 复用父类构造函数
    setmetatable(self, SavingAccount)      -- 关键：把实例的元表换成子类
    self.rate = rate or 0.03               -- 子类自己的字段
    return self
end

function SavingAccount:getInterest()
    return self.balance * self.rate
end

local sa = SavingAccount.new(1000, 0.05)
print(sa:getBalance())    -- 1000   （继承自 Account）
print(sa:getInterest())   -- 50     （子类方法）
```

> `SavingAccount = setmetatable({}, { __index = Account })`：子类自己也是一个「对象」，它的元表 `__index` 指向父类——所以子类能访问父类的静态字段/方法。实例的元表则是子类。

**链式多级继承**同理：孙类的 `__index` 指向子类，子类的 `__index` 指向父类，查找链条不断加长（与元表篇「自索引实现链式继承」一致）。

## 4. 重写（Override）

子类定义同名方法即覆盖父类实现；子类方法内可用 `父类.方法(self, ...)` 显式调用父类版本（类似 Java 的 super）：

```lua
-- 在 3 的基础上：SavingAccount 重写 getBalance，返回带利息后的总额
function SavingAccount:getBalance()
    -- 显式调用父类方法：Account.getBalance(self)
    local base = Account.getBalance(self)
    return base + self:getInterest()
end

print(sa:getBalance())  -- 1000 + 50 = 1050（重写后）
```

> 要点：父类方法通过 `Account.getBalance(self)` 显式调用（不是冒号），手动传入 self。

## 5. 成员私有化

Lua 没有 private 关键字。两种主流方案：

**方案一：闭包私有（类似 Java 的 private 字段）**

```lua
-- 用局部变量做私有字段，只有闭包内函数能访问
function newPerson(name)
    local privateName = name   -- 私有变量，外部无法直接访问
    return {
        getName = function() return privateName end,
        setName = function(n) privateName = n end,
    }
end

local p = newPerson("zs")
print(p.getName())    -- zs
-- print(p.privateName)  -- nil，外部访问不到
p.setName("ls")
print(p.getName())    -- ls
```

**方案二：命名约定（下划线前缀表示私有，Lua 社区惯例）**

```lua
local obj = {
    _secret = "内部数据",   -- 约定：下划线开头 = 私有（只是约定，实际可访问）
    publicField = "公开数据",
}
```

> 注意：闭包私有**每个实例单独保存一份私有变量**（内存开销），且丢失了继承性（子类无法访问父类私有）；约定式私有则有真正的继承性。大量实例场景用约定式，强调封装安全用闭包式。

## 6. 常见踩坑

- `function T:method()` 定义在类上时 self 是**类**（调用者是类）；定义在实例上时 self 是**实例**——搞清楚调用者是谁
- 忘记 `__index = 类`，实例调用方法报 `attempt to call a nil value`
- 子类构造函数忘记 `setmetatable(self, 子类)`，实例的元表还是父类，子类方法调不到
- `:` 与 `.` 混用：`obj.method()`（点）不会自动传 self，方法里用 self 会报 nil
- 冒号定义的方法用点调用：`Account.new` 定义用冒号则 `Account.new(balance)` 会多传一个 self 参数导致错位——构造函数统一用点定义
