# 数据库总览

> 本文是「数据库」知识域的**统一入口**，索引 4 大分支：**MySQL**、**PostgreSQL**、**Redis**、**DB 通用理论**。
>
> - **DB 通用理论** = 能脱离具体某库独立成立的概念（事务/锁/MVCC/ACID/隔离级别），各库（PG/MySQL/Redis）通过 wikilink 回链通用篇，通用篇不重复库里实现。
> - **具体库** = 只有该库才有的语法/内部实现/命令/实测。

### 3.2 PostgreSQL

功能最全的开源关系库（ACID/MVCC/JSONB/全文/空间/向量全内置），被誉为"开源数据库中的瑞士军刀"。详见 **00-PostgreSQL总览**（见知识库）。

### 3.3 MySQL

📌 **占位**（待总结）。对照记忆：**"MySQL 是够用的关系库，PG 是啥都能干的关系库"**；互联网高并发简单 CRUD 场景 MySQL 生态更成熟。见 **00-MySQL总览**（见知识库）。

### 3.4 Redis

内存 NoSQL，单线程高吞吐，做缓存/消息/分布式锁。常见于 MySQL/PG 前的缓存层。见 **00-Redis总览**（见知识库）。

## 4. 怎么用这套笔记

1. **先读通用层**：事务 → 锁 → MVCC，建立跨库心智模型。
2. **再看具体库**：PG 全量可读；MySQL 当前占位；Redis 是 NoSQL 侧重缓存。
3. **对照记忆**：各库笔记里的跨库对照表（MVCC 两套方案、默认隔离级别、锁实现）都会回链通用层或对方库，遇到"某概念哪库实现"从 DB 通用理论 → 具体库层层下钻。
