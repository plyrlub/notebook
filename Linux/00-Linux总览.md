# 00-Linux 总览

> 面向**后端工程师、Linux 基础较弱**的系统化 Linux 学习笔记。覆盖 Ubuntu / CentOS 双发行版，以「登录授权 → 常用命令 → 系统优化 → 安全加固」为主线。
> 定位：**应用层为主，不追底层**（内核调度/文件系统内部原理不展开），但命令组合、最佳实践、排障套路会细化到可复制。

---

## 📋 总纲

- ① **用户管理与登录授权**：用户/组管理、sudo 授权体系、SSH 登录配置——后端上服务器的第一道门槛
- ② **文件权限与属主**：chmod/chown/umask、SUID/SGID/Sticky 特殊位、ACL 扩展权限——多用户协作与安全基线
- ③ **常用命令速查**：进程/网络/磁盘/文本处理场景化命令 + 三剑客组合——日常高频操作全覆盖
- ④ **系统优化与性能排查**：资源监控、四类经典问题排查套路、内核参数、ulimit——后端部署与排障实战
- ⑤ **安全加固**：SSH 加固、防火墙双版本、日志审计——上线前的安全基线

---

## 1. 版本说明（Ubuntu vs CentOS）

| 维度 | Ubuntu（LTS） | CentOS Stream / RHEL 系 |
| ---- | ---- | ---- |
| 包管理 | `apt`（dpkg） | `dnf`（旧版 `yum`） |
| sudo 组 | `sudo` 组 | `wheel` 组 |
| 防火墙 | `ufw` | `firewalld` |
| 默认 Shell | bash | bash |
| 适用场景 | 个人/云主机、开发环境 | 企业服务器、存量生产 |

> 本系列正文默认给 Ubuntu 命令，CentOS 差异处单独标注 `（CentOS: xxx）`。

- [01-用户管理与登录授权](01-用户管理与登录授权.md) — 用户/组管理、sudoers 语法、SSH 密钥登录、最小权限实践

- [04-系统优化与性能排查](04-系统优化与性能排查.md) — top/free/iostat 监控、CPU/内存/磁盘/端口四类排查套路、sysctl/ulimit

## 3. 学习路线

1. 先过 **01 用户管理与登录授权**——会用 `sudo`、能建用户配密钥，是后端上手服务器的前提
2. 再刷 **03 常用命令速查**——进程/日志/端口是日常最高频三件事
3. 遇到权限报错回查 **02 文件权限与属主**；部署上线前过 **04 系统优化** 和 **05 安全加固**

> 每篇末尾有「命令组合」小节，建议在真实服务器上逐条敲一遍（可用云主机或 Docker Ubuntu/CentOS 容器练习）。
