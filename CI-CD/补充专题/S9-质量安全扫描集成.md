# S9. 质量检测与安全扫描的 Pipeline 集成

> **专题编号：S9**。被引用章节：第 05、06、08 章。

---

## 一、介绍：解决"工具怎么集成到 Pipeline"的问题

**要解决的核心问题**：不是"用哪些工具"（这些主路径里已有），而是**每个工具在 Pipeline 的哪个 Stage 介入、怎么配置、失败了怎么阻断、Java/Python/Lua 三语言的差异**。

## 二、执行顺序总览

```
[Checkout]
    ↓
[Lint + 快速静态检查]  ←  luacheck / flake8 / checkstyle（廉价检查，秒级）
    ↓
[凭据泄露扫描 Gitleaks/TruffleHog]  ←  越早越好，发现密钥立即终止
    ↓
[单元测试 + 覆盖率]
    ↓
[SAST 静态扫描]  ←  SonarQube / CodeQL（较重，可异步并行跑，不阻塞后续 Stage，只在合并门禁校验）
    ↓
[SCA 依赖扫描]  ←  Dependabot / OWASP Dependency-Check / Snyk（检查第三方库漏洞）
    ↓
[Build 构建]
    ↓
[Trivy 文件系统扫描]  ←  对构建产物做文件系统级漏洞扫描（在镜像打包之前）
    ↓
[镜像构建 Docker Build]
    ↓
[Trivy 镜像扫描]  ←  对镜像 OS 包 + 应用依赖做扫描，高危漏洞则**阻断推送**
    ↓
[生成 SBOM + Cosign 签名]  ←  与镜像一起推送到制品仓
    ↓
[推送镜像 / 制品]
    ↓
[集成测试 / E2E]  ←  在类生产环境跑
    ↓
[部署]
```

## 三、质量检测工具选型对比（2026 年）

**表 9-1：质量检测与安全扫描工具选型**

| 工具 | 类型 | 优势 | 劣势 | 推荐场景 |
| ---- | ---- | ---- | ---- | -------- |
| **SonarQube** | SAST + 质量门 | 规则全、支持语言多、质量门体系完善 | 需自建服务、首次配置量大 | **企业级首选**（有专门的质量团队） |
| **GitHub CodeQL** | SAST | 零基础设施、语义分析强、GitHub 原生集成 | 只在 GitHub 平台、社区版有功能限制 | GitHub 托管项目首选 |
| **SonarCloud** | SAST（SonarQube SaaS 版） | 零运维、开箱即用 | 免费版有限制 | 中小团队 / 开源项目 |
| **Trivy** | 容器+文件+依赖扫描 | 一个工具覆盖多层扫描、速度快、规则新 | 只有扫描，无代码异味/重复率分析 | **2026 容器安全标配**，必装 |
| **Grype** | 容器+依赖扫描 | 与 Trivy 功能重叠，Anchore 生态 | 社区活跃度略低于 Trivy | 已在用 Anchore 的团队 |
| **Snyk** | SCA + SAST + 容器 + IaC | 一站式 SaaS、漏洞情报准 | 收费版不便宜、自建难 | 预算充足的中小团队 |

## 四、具体集成要点

### 4.1 SonarQube 集成

**sonar-project.properties 配置**：
```properties
sonar.projectKey=myorg:myapp
sonar.projectName=My App
sonar.projectVersion=1.0

sonar.sources=src
sonar.tests=tests
sonar.exclusions=**/node_modules/**,**/*.spec.ts

# 覆盖率
sonar.python.coverage.reportPaths=coverage.xml
sonar.coverage.jacoco.xmlReportPaths=target/site/jacoco/jacoco.xml

# 质量门（在 SonarQube UI 配置）
# - Coverage < 80% → FAIL
# - Duplicated lines > 3% → FAIL
# - Blocker/Critical issues > 0 → FAIL
```

**Maven 集成**：
```xml
<plugin>
  <groupId>org.jacoco</groupId>
  <artifactId>jacoco-maven-plugin</artifactId>
  <executions>
    <execution>
      <goals><goal>prepare-agent</goal></goals>
    </execution>
    <execution>
      <id>report</id>
      <phase>test</phase>
      <goals><goal>report</goal></goals>
    </execution>
  </executions>
</plugin>
<plugin>
  <groupId>org.sonarsource.scanner.maven</groupId>
  <artifactId>sonar-maven-plugin</artifactId>
  <version>3.10.0</version>
</plugin>
```

```bash
# CI 中跑
mvn clean verify sonar:sonar \
  -Dsonar.host.url=https://sonar.example.com \
  -Dsonar.login=$SONAR_TOKEN
```

**GitHub Actions 集成**：
```yaml
- name: SonarQube Scan
  uses: SonarSource/sonarqube-scan-action@v1
  env:
    SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
    SONAR_HOST_URL: https://sonar.example.com
```

**质量门检查**（阻断合并）：
```yaml
- name: SonarQube Quality Gate
  uses: SonarSource/sonarqube-quality-gate-action@v1
  timeout-minutes: 5   # 防止挂死
  env:
    SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
```

### 4.2 CodeQL 集成（GitHub 原生）

```yaml
# .github/workflows/codeql.yml
name: CodeQL
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  analyze:
    runs-on: ubuntu-latest
    permissions:
      security-events: write    # 必须有，才能上传结果
    strategy:
      matrix:
        language: [python, java]   # 项目实际语言
    steps:
      - uses: actions/checkout@v4
      - uses: github/codeql-action/init@v3
        with:
          languages: ${{ matrix.language }}
      - uses: github/codeql-action/autobuild@v3
        # 若 autobuild 失败，手动指定：
        # with:
        #   setup-java: 21
        #   maven-version: 3.9
      - uses: github/codeql-action/analyze@v3
```

### 4.3 Trivy 双位置集成

**位置 1：构建前扫文件系统**
```bash
# 在 docker build 之前，对源码 + 依赖做扫描
trivy fs --severity CRITICAL,HIGH --exit-code 1 .
```

**位置 2：镜像构建后扫镜像**
```bash
# 构建后扫镜像，高危阻断推送
trivy image --severity CRITICAL,HIGH --exit-code 1 myapp:v1.2.0
```

**GitHub Actions 集成**：
```yaml
- name: Trivy FS Scan
  uses: aquasecurity/trivy-action@master
  with:
    scan-type: fs
    severity: CRITICAL,HIGH
    exit-code: 1
    ignore-unfixed: true

- name: Build image
  run: docker build -t myapp:${{ github.sha }} .

- name: Trivy Image Scan
  uses: aquasecurity/trivy-action@master
  with:
    image-ref: myapp:${{ github.sha }}
    severity: CRITICAL,HIGH
    exit-code: 1
    format: sarif
    output: trivy-results.sarif

- name: Upload Trivy results to GitHub Security
  uses: github/codeql-action/upload-sarif@v3
  with:
    sarif_file: trivy-results.sarif
```

**`.trivyignore` 使用原则**：
- 只忽略"已被评估且接受风险"的漏洞
- 每条 ignore 必须带 CVE 编号 + 评估理由 + 跟踪期限
- 定期 review `.trivyignore`，到期必须删除

```
# .trivyignore 示例
CVE-2023-12345  # 评估：仅影响未用功能，2026-09-01 删除
CVE-2024-67890  # 评估：上游已修但镜像未发新版本，等 ubuntu:24.04 更新
```

### 4.4 SCA 扫描集成

**Dependabot 自动 PR 策略**：
```yaml
# .github/dependabot.yml
version: 2
updates:
  - package-ecosystem: pip
    directory: /
    schedule:
      interval: weekly
    open-pull-requests-limit: 5
    # 仅自动合并 patch 升级，minor/major 人工 review
    allow:
      - update-type: version-update:semver-patch
  - package-ecosystem: maven
    directory: /
    schedule:
      interval: weekly
```

**OWASP Dependency-Check（Maven）**：
```xml
<plugin>
  <groupId>org.owasp</groupId>
  <artifactId>dependency-check-maven</artifactId>
  <version>9.0.9</version>
  <configuration>
    <failBuildOnCVSS>7</failBuildOnCVSS>   <!-- CVSS ≥ 7 阻断构建 -->
    <formats>HTML,JSON</formats>
  </configuration>
  <executions>
    <execution>
      <goals><goal>check</goal></goals>
    </execution>
  </executions>
</plugin>
```

### 4.5 Gitleaks / TruffleHog 集成

```yaml
- name: Gitleaks
  uses: gitleaks/gitleaks-action@v2
  env:
    GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
  with:
    config-path: .gitleaks.toml
```

**.gitleaks.toml 自定义规则**：
```toml
[allowlist]
description = "Allowed patterns"
regexes = [
  # 示例：允许测试用假密钥
  '''test_key_[a-z0-9]{20}''',
]
paths = [
  '''(^|/)tests/.*\.py$''',
  '''(^|/)spec/.*\.lua$''',
]
```

## 五、阻断策略总原则

| 类型 | 触发条件 | 处理 |
| ---- | -------- | ---- |
| **硬阻断** | 密钥泄露、CRITICAL/HIGH 漏洞、Sonar Quality Gate FAIL | 不允许合并，立即终止 |
| **软告警** | 代码异味、低覆盖、MEDIUM 漏洞 | 告警 + 逾期跟进，不阻断 |
| **不阻断** | LOW 漏洞、INFO 信息 | 仅记录 |
