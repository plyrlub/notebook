### GitLab Pipeline 全景流程图（承诺产出）

> **交付时机**：第 04 章学完 GitLab CI 后（学完整工具配置后，把所有点串成一张图）。
> **交付位置**：`assets/04-gitlab-pipeline-full.svg`（SVG 优先）。
> **图中涵盖**：
> - 所有 Stage 顺序（Pre → Checkout → Lint → Secrets Scan → Test → SAST → SCA → Build → Trivy FS → Docker Build → Trivy Image → SBOM + Sign → Push → Integration/E2E → Deploy → Verify → Post）
> - 每个 Stage 内部关键 Job、并行/串行/依赖关系
> - 质量与安全扫描嵌入的精确位置及阻断点（红叉/绿勾）
> - S10 的 Checkout / 缓存 / 制品保存 / 镜像推送 各关键动作对应位置
> - S1 凭据注入点、S4 SBOM + 签名点、S5 安全防护点
> - 失败流转：哪些 Stage 失败终止后续，哪些是软告警
>
> GitHub Actions / Jenkins 版本流程图在学完对应工具后可选补。
